ROS 機器人
數據可視化平台

透過AI Native 開發的機器人表現以及軌跡分析工具，讓開發者能夠在同一個時間軸上同步查看機器人移動影片、XR 虛擬實境畫面與運動數據對比以及分析，進行Debug。

01 / PROBLEM

該平台核心解決問題

機器人影片、XR 畫面與運動數據分散在不同檔案，開發者需要反覆打開檔案、手動對齊時間才能找出異常。將資料整合在同一條時間軸，讓問題發生當下的畫面、軌跡與數值能直接對照分析。

以前：讀 CSV 與 log
  1. 開多個 CSV、log 視窗逐一對照
  2. 回放影片找出問題發生的那一秒
  3. 截圖、手動對齊時間再比對數值
→
現在：同一條時間軸
  1. 影片、軌跡與數據自動同步
  2. 點圖表直接跳到該時間點的畫面
  3. 異常點當下就能對照所有資料來源

02 / FEATURES

主要核心功能

應用在 XR 環境中的機器人，需要準確停在虛擬物件顯示位置，提供使用者可以觸碰的實體支撐。該平台協助開發者診斷機器人表現是否異常。

01

虛實位置一致性

用演算法比對機器人座標與 ArUco 追蹤到的位置，驗證虛實一致性。

02

機器人表現診斷
