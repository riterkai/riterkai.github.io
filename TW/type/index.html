UX Case Study — HTC Vive / VR Interaction
3D OBJECT
MANIPULATION

讓虛擬空間中的物件，
像真實世界一樣直覺操作。

為 VR 世界定義選取、移動、旋轉與縮放的操作規範，並做成可直接試玩的互動原型。

01 · 使用情境

從選取到放下，一個完整的操作循環

Select

選取物件

手把射線指向物件，扳機確認選取。

Move

移動與旋轉

拖曳軸向控制點，限制單一方向移動。

Scale

等比縮放

雙手拉開或靠近，保持物件比例。
